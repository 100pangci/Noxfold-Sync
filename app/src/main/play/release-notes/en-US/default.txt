v2.1.5.0: Syncthing core upgraded from v2.1.3 to the stable v2.1.5 release.

## New
* **Syncthing core pinned to stable v2.1.5**: bundled core upgraded from v2.1.3 — config format (version 52) and REST API unchanged, no app-side code changes required
* Core v2.1.4: all outgoing HTTP requests now send a User-Agent header (upstream #10867)
* Core v2.1.5: build / packaging fixes upstream; no functional changes for the Android app

## Notes
* App UI, SAF bridge and root mode are unchanged since v2.1.3.3

## Known limitations
* Root mode is experimental: verified on a single Magisk / HyperOS device; KernelSU untested
* Implicit broadcasts to AppConfigReceiver are blocked by Android 16 / HyperOS — use explicit broadcasts (see wiki)
* Dialogs have no predictive-back animation (compose-ui platform gap)

## 新增
