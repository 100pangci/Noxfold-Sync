v2.1.6.0-rc.1: SAF synchronization and configuration backup reliability improvements. Pre-release for testing; not the final stable release.

## Fixes
* **SAF bridge**: stage and verify copied files before replacement, protect concurrent changes, and retry failed merge operations without advancing an unverified snapshot
* **Folder setup/removal**: wait for Syncthing to accept configuration and ignore rules before continuing; report failures instead of starting an incomplete sync
* **Config backups**: validate exports and imports before installation, preserve the previous backup, and roll back config, database, and preferences if an import fails
* **Config files**: replace config and ignore-list files transactionally to avoid leaving partial files after a write failure

---

v2.1.6.0-rc.1：改进 SAF 同步桥和配置备份的可靠性。本版本为测试预览版，尚非正式稳定版。

## 修复与改进
* **SAF 同步桥**：复制完成并校验后再替换目标，避免覆盖并发修改；合并失败时保留未确认状态并重试
* **文件夹配置**：等待 Syncthing 确认配置和忽略规则后再继续；失败时明确提示，不启动不完整的同步
* **配置备份**：导入/导出先校验再安装；导出失败保留旧备份，导入失败时回滚配置、数据库和偏好设置
* **配置文件**：事务式替换 config 与忽略列表，减少写入失败造成部分文件的风险
