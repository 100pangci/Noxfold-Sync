v2.1.7.0 — Stable release.

## Highlights
* **Syncthing core v2.1.7** is now bundled. This is a maintenance release; the app itself has no user-facing changes since v2.1.6.1.

## Upstream fixes (Syncthing v2.1.7)
* **Model**: verify local changes before applying the metadata shortcut; copy parent ownership correctly; compare blocks properly when reconciling receive-only folders.
* **Database**: handle missing max-sequence file entries, avoid early garbage collection of deleted receive-encrypted files, and stop generating unbounded prepared statements.
* **Protocol**: validate incoming messages and turn panics on malformed data into protocol errors; cap body sizes for requests to public services.
* **Discovery**: skip unnecessary identical global announce updates and honour retry-after.

## Notes
* No database or configuration migration is required; upgrading from v2.1.6.x is a drop-in update.

v2.1.7.0 — 正式稳定版。

## 主要更新
* **内置 Syncthing core 升级至 v2.1.7**。本次为维护性更新，应用本身相对 v2.1.6.1 没有面向用户的变化。

## 上游修复（Syncthing v2.1.7）
* **模型**：应用元数据快捷路径前先校验本地变更；正确复制父目录属主；仅接收文件夹重建时正确比较数据块。
* **数据库**：处理缺失的 max-sequence 文件记录；避免已删除的接收加密文件被过早回收；不再生成无上限的预编译语句。
* **协议**：校验入站消息并将畸形数据引发的 panic 转为协议错误；限制发往公共服务请求的报文体大小。
* **发现服务**：跳过无变化的全局公告更新，并遵守 retry-after。

## 说明
* 无需数据库或配置迁移，从 v2.1.6.x 直接升级即可。
